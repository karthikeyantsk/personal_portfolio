# 🌐 Karthikeyan T S – Personal Portfolio Website

This is a fully responsive and animated Personal Portfolio Website designed to showcase my skills, education, certifications, internship experience. The website is built using modern & clean UI components, providing elegant navigation, interactive animations, and an engaging user experience.

## 📁 Project Overview

The website includes the following sections:

- Welcome Section
- Who I Am (About)
- Technical Skill Set
- Project Portfolio
- Certifications & Achievements
- Contact Section
- Feedback System with Rating
- Responsive Social Sidebar
- Animation Effects (ScrollReveal & Click Effects)

Built to help recruiters & companies quickly understand my technical expertise and evaluate my work through GitHub project links.

## 🎯 Key Features

✔ Modern UI with Neon Gradient Effects  
✔ Responsive for all screens (Mobile, Tablet, Desktop)  
✔ Interactive Hover & Scroll Animations _(ScrollReveal JS)_  
✔ Smooth Click Bubble Animation ✨  
✔ Feedback Form with Rating ⭐  
✔ Contact Form with Webhook Integration  
✔ Organized Project Gallery  
✔ Certification Gallery + Dedicated Certificates Page  
✔ Sidebar Social Media Expand/Collapse  
✔ Creative Typography (Cursive Branding)
